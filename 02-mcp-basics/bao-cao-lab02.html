Khẳng định 1 — schema tự sinh từ type hints

Đây là điểm README nhấn mạnh nhất. Dưới đây là schema thật mà server công bố qua list_tools(), dump nguyên văn tại runtime:

list_tools() → input_schema
{
  "properties": {
    "city": { "title": "City", "type": "string" }
  },
  "required": [ "city" ],
  "type": "object",
  "title": "get_weatherArguments"
}

Toàn bộ schema trên sinh ra từ 4 dòng source, không có dòng nào mô tả schema bằng tay:

Trong sourceSinh ra trong schema
city: str"type": "string"
tham số không có giá trị mặc định"required": ["city"]
docstring của hàmdescription = “Lấy thời tiết hiện tại của một thành phố.”

Khẳng định 2 — server thực thi, không phải client

Ở bài 01, app chạy hàm. Ở đây trách nhiệm đó chuyển hẳn sang tiến trình server. Hai bằng chứng độc lập:

  1. hasattr(weather_client, 'get_weather') trả về False — client không hề có hàm đó, nó chỉ gửi tên tool qua stdio
  2. Gọi city="Hue" (không có trong _MOCK_DB) trả về 'Hue: 28°C, không có dữ liệu chi tiết' — nhánh mặc định nằm trong server chạy, client không biết gì về _MOCK_DB

Bằng chứng thứ hai mạnh hơn bằng chứng thứ nhất: nó cho thấy client không chỉ thiếu hàm, mà còn không nắm được cả dữ liệu lẫn logic xử lý trường hợp thiếu dữ liệu. Đúng như README nói: “client không cần biết code bên trong”.

Đăng ký server với AI client

README hướng dẫn dùng claude mcp add. Máy này chạy Claude Code dưới dạng extension VS Code nên không có CLI claude trong PATH; lệnh đó chỉ sinh ra file cấu hình, nên file được tạo trực tiếp ở phạm vi project:

.mcp.json — gốc repo
{
  "mcpServers": {
    "weather": {
      "command": "python",
      "args": ["…\\02-mcp-basics\\weather_server.py"]
    }
  }
}

Kiểm chứng bằng cách đọc chính file này rồi kết nối bằng đúng command + args trong đó, chạy từ một thư mục hoàn toàn khác (C:\Users\vohon):

kết quả
Ket noi OK -> server 'weather'
Tool cong bo: ['get_weather']
call_tool -> Hanoi: 29°C, trời mưa

Chạy được từ thư mục không liên quan chứng minh đường dẫn tuyệt đối trong cấu hình là đúng và không phụ thuộc thư mục hiện hành — điều kiện để AI client khởi động server ở bất kỳ đâu.
